# 🪟🏝️ SQL Island Extended – Window Functions Edition

**Group T7:** Rino Moreno Albertin, Lana Cvijic, Joël Tauss, Endrit Nazifi

This repository contains our term project for the *Data Management (MSE, Spring Semester 2026)* course taught by Prof. Stefan Keller.

The goal of this project is to extend the original SQL Island game with **modern SQL window functions**, enabling players to learn analytical SQL concepts in an interactive and gamified way.

---

## 📖 Project Overview

SQL Island is an educational SQL adventure game. In this extension, we introduce **window functions** as a new gameplay mechanic to teach:

* Analytical queries
* Partitioned calculations
* Ranking and comparison within groups
* Sequential and cumulative computations

These concepts are part of **modern SQL standards (SQL:2003+)** and are essential for data analytics and data engineering .

---

## 🎮 How to Play

You can play the extended version of SQL Island by following these steps:

1. Download the file:

   ```
   t7_island_addon.xml
   ```

2. Open the SQL Game Console:
   👉 [https://eskuel.infs.ch](https://eskuel.infs.ch)

3. Upload the XML file into the console

4. Start solving the missions 🎯

---

## 🧩 Game Content

The file **`t7_island_addon.xml`** contains:

* Storyline extension of SQL Island
* New missions focused on window functions
* SQL challenges with increasing difficulty
* Interactive feedback and learning progression

The missions guide the player through concepts such as:

* `OVER()` clause
* `PARTITION BY` vs `GROUP BY`
* `ORDER BY` in window functions
* Window frames (`ROWS` / `RANGE`)
* Ranking functions (`RANK()`, `DENSE_RANK()`)
* Analytical functions (`FIRST_VALUE()`, `LAST_VALUE()`, etc.)

---

## 🎯 Learning Objectives

By completing the game, players will:

* Understand the difference between aggregation and window functions
* Learn how to analyze data **without collapsing rows**
* Apply ranking and comparison within groups
* Gain intuition for advanced SQL analytical queries

Window functions are especially important in modern data workflows such as:

* Data analytics
* Reporting and dashboards
* Data warehousing
